CutieCalce<br>
<br>
A fun, interactive calculator built with HTML, CSS, and JavaScript.
<br>
Features:
Basic Arithmetic: +, -, *, /.<br>
Smart Input: Prevents you from typing two operators in a row.<br>
Divide by Zero Protection: Catches division by zero and gives a warning.<br>
Auto-Correction: If you click = with a hanging operator (like 5+ =), it automatically calculates the number.<br>
"Human" Status Messages: A dynamic text box below the calculator reacts to inputs, and gives feedback.<br>
Responsive Grid Layout: Built using CSS Grid.<br>

Tech Stack:<br>
HTML5<br>
CSS3<br>
JavaScript<br>
